1. About Keuangan-CBL

Keuangan-CBL (Financial SaaS) is a financial workflow tool developed and operated by Muhammad Fikri. It assists with document collection, transaction extraction, and accounting administration.

The software is currently in an internal pilot stage for our company's everyday operations and testing.

2. Pilot and Internal Use

This system is intended for authorized internal personnel participating in the pilot. Features, extraction tools, and integrations may change as we test and improve the system.

3. User Responsibilities and Checking Data

Authorized users must take care when submitting and reviewing information:

  • Check financial information: OCR and AI extraction can make mistakes. Authorized users must always review document details, amounts, project assignments, and counterparty names before approving an entry.
  • Account security: Keep your login credentials safe and operate only on documents related to your assigned organization.

4. Acceptable Use

When using the application or sending files via WhatsApp, users must:

  • Only upload genuine company financial and project documents (such as invoices, bills, receipts, and payment slips).
  • Not upload malicious files, scripts, or harmful content.
  • Not send unrelated files, personal photos, or spam to connected messaging channels.

5. Third-Party Services and Availability

The application relies on third-party services, including the Meta WhatsApp Cloud API and cloud infrastructure providers. Because these external services can experience downtime or delays, uninterrupted availability cannot be guaranteed.
